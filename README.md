## 🌟 Executive Summary

**English Master** is a production-grade, interactive educational web platform engineered specifically for banking examination aspirants targeting **SBI Clerk (Junior Associate), IBPS Clerk / Customer Service Associate (CSA), and IBPS RRB Office Assistant / Officer Scale-I**.

Unlike static question banks or generic grammar websites, this platform functions as a **Personal English Tutor, Concept Learning System, PYQ Analysis System, Vocabulary Builder, Reading Speed Trainer, Practice Engine, TCS iON Mock Test Engine, Error Analysis System, and Revision System**.

## 🚀 Key Feature Pillars

### 1. 📚 24 Complete Grammar Chapters with "Beginner Mode"
Every grammar chapter is structured with rigorous pedagogical depth:
- **Concept & Syntax Rule**: Formal definition with linguistic precision.
- **"Explain Like I'm a Beginner"**: Plain-language simplified translation (e.g. *"The verb agrees with the real subject, not necessarily the nearest noun"*).
- **Correct vs Incorrect Side-by-Side**: Direct comparative sentences highlighting the exact violation.
- **Why is it Wrong?**: Step-by-step grammatical dissection.
- **Bank Exam Shortcut**: Time-saving operational rules (e.g., thumb rule for parenthetical phrases, pronoun sequence 231 vs 123).
- **Exam Trap Alert**: High-frequency acoustic traps designed by banking examiners.
- **PYQ Shift References**: Exact shifts where the rule appeared (SBI Clerk, IBPS Clerk 2020–2026).

**Chapters Covered:**
1. Parts of Speech & Concord
2. Subject-Verb Agreement (Proximity, Parenthetical connectors, 'One of the', 'A number of')
3. Tenses & Aspect (Definite past time markers, Double past actions, Stative verb bans)
4. Articles & Determiners (Phonetic sound rules: 'a European', 'an honest', 'an FIR', 'the' in parallels)
5. Prepositions & Fixed Collocations ('adhere to', 'cope with', 'abide by', transitive no-preposition rules)
6. Conjunctions & Correlative Pairs ('No sooner... than', 'Hardly... when', 'Lest... should')
7. Adjectives, Modifiers & Degree (Latin comparatives 'senior to', 'preferable to', 'little vs few')
8. Adverbs & Negative Inversion ('Seldom had he', 'Hardly did they', 'Little did we know')
9. Pronouns & Case Agreement (Who vs Whom, Order of personal pronouns 231 vs 123)
10. Modals & Semi-Modals (Would rather, Had better, Must vs Ought to)
11. Conditional Sentences (Types 0, 1, 2, 3 and third conditional inversion: 'Had + V3')
12. Active & Passive Voice Transformations
13. Direct & Indirect Speech
14. Non-Finite Verbs (Gerunds following 'to': 'look forward to', 'with a view to'; Bare infinitives)
15. Parallelism in Series & Correlative Structures
16. Redundancy & Superfluous Expressions ('return back', 'repeat again', 'cousin brother')
17. Dangling Modifiers & Unattached Participles
18. Comparison of Unequal Entities ('that of / those of')
19. Question Tags & Polarity
20. Clauses & Sentence Architecture (Noun, Adjective, Adverb clauses)
21. Determiners & Quantifiers (Much/Many, Each/Every, Few/Little)
22. Phrasal Idiomatic Structures
23. Inversion Rules & Mechanics
24. Common Exam Errors Master List (Top 50 recurring banking traps)

### 3. 🎯 527 Verified Bilingual Questions with Strict Provenance
- **Strict Data Provenance**: Every question is certified as:
  - `ACTUAL PYQ` (149 Questions): Exact questions from banking shifts.
  - `MEMORY-BASED PYQ` (126 Questions): Reconstructed questions from student exam recalls.
  - `PYQ-STYLE` (126 Questions): High-probability pattern variants.
  - `ORIGINAL PRACTICE` (126 Questions): Conceptual drills created by English faculty.
- **IBPS 5-Option Pattern (A–E)** with authentic negative marking (-0.25 penalty per wrong answer).
- **3-Level Progressive Hint System**:
  - 💡 Hint 1: Concept rule
  - 💡 Hint 2: Elimination clue
  - 💡 Hint 3: Specific solution guidance
- **Confidence Tracker**: Tracks whether you are *Guessing*, *Unsure*, *Fairly sure*, or *Very sure* to detect overconfidence and underconfidence.

## ⚡ Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or newer recommended)
- [Git](https://git-scm.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/raghavendra-exp/english-master.git
cd english-master
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173/`.

### 4. Build for Production
```bash
npm run build
```

### 5. Preview Production Build Locally
```bash
npm run preview
```

## 🌐 Deploying to GitHub Pages

The project includes an automated GitHub Actions deployment workflow.

### Deployment Instructions:
1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/raghavendra-exp/english-master.git
   git branch -M main
   git push -u origin main
   ```
2. On GitHub, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions** (or select the `gh-pages` branch).
4. Within 1-2 minutes, your website will be live at:
   `https://raghavendra-exp.github.io/english-master/`
